# 验收标准

1. 无 Token 启动时进入欢迎页，邮箱登录入口可稳定进入登录页。
2. 有未过期 Token 和缓存用户时恢复已登录状态。
3. access token 过期但 refresh token 有效时刷新成功并恢复已登录状态。
4. access token 过期且无法刷新时清理全部本地认证数据，Redux 变为未登录，并稳定停留在欢迎页或邮箱登录页。
5. 多个并发受保护请求返回 401 时，等待队列全部结束，只执行一次会话失效处理，不发生重复导航。
6. 登录接口本身返回 401 时显示登录错误，不触发全局会话失效重定向。
7. 认证状态和 API 拦截器相关自动化测试通过。
