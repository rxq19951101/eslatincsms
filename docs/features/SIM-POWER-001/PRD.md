# 模拟充电桩共享功率上限

## 背景

当前 `charger-sim` 为同一充电桩的每个枪口独立使用 `power_kw`。一台标称总功率
60kW 的双枪模拟桩在两枪并发时会各上报 60kW，形成不真实的 120kW 总功率。

## 目标

- 为单台模拟充电桩增加可选的整桩共享功率上限。
- 一个活跃枪口时，允许其使用不超过自身上限和整桩上限的功率。
- 多个枪口并发时，在活跃枪口之间公平分配整桩可用功率。
- 某枪口停止后，剩余枪口在下一次计量计算时自动获得释放的功率。
- `MeterValues` 的瞬时功率和累计电量必须使用实际分配功率。
- 未配置共享功率上限时保持现有行为。

## 功率分配规则

- 只对存在进行中 OCPP transaction 的枪口分配功率。
- 每枪的 `power_kw` 是该枪请求/最大功率。
- `shared_power_limit_kw` 是整桩总功率上限，必须大于 0。
- 使用公平、受上限约束的分配：先均分，低于均分额度的枪口只取自身上限，
  剩余容量继续在其他活跃枪口之间均分。
- 60kW 双枪且两枪上限均为 60kW 时：单枪 60kW，双枪各 30kW。
- 分配结果不得为负，活跃枪口功率之和不得超过整桩上限。

## 配置契约

- `run-one` 新增可选参数 `--shared-power-limit-kw`。
- `run-many` 的 charger 配置新增可选字段 `shared_power_limit_kw`。
- 缺省或未提供该字段时，每枪继续独立使用自己的 `power_kw`。

## 非目标

- 不实现真实充电桩的动态负载管理协议。
- 不修改 CSMS、Admin、App 或数据库结构。
- 不改变连接器类型；类型仍由 Admin 中的 EVSE 配置管理。
- 不部署或启动生产模拟器。
