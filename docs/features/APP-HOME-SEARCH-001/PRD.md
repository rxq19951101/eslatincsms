# App 首页三语搜索框布局修复

## 问题

首页搜索框的容器和输入框同时使用无边界 `flex: 1`。在西班牙语标题换行、不同屏幕宽度或键盘弹出时，搜索框可能被列表/地图切换栏压缩或遮挡。iOS 还会错误显示 AutoFill 浮层。

## 目标

- 搜索框在中文、英文和西班牙语下始终完整可见。
- 搜索框与列表/地图切换栏各占独立纵向区域，不发生覆盖。
- 搜索输入不触发账号 AutoFill。
- 保留现有站点名称、地址和接口类型筛选逻辑。

## 实现范围

- 仅修改 App 首页搜索区域及其直接测试。
- 搜索框使用稳定的宽度和最小高度，不依赖无边界 flex 撑开。
- 配置搜索键盘、清除按钮、自动更正和 AutoFill 行为。
- 验证三语占位文字和窄屏布局约束。

## 非范围

- 不调整首页卡片、标题品牌区、列表/地图数据逻辑。
- 不实现外部地图导航。
- 不修改通用 `TextField` 的全局视觉规范。
