# 三端充电闭环缺陷修复

修复人工联调发现的启动请求风暴、远程命令结果失真、活动会话恢复、内部数据库 ID 暴露、三语言遗漏、设备统计不一致和 SIM E2E 脏会话残留。

## 冻结产品规则

- App 默认展示所有租户的公开充电桩；暂不开发租户隐藏功能。
- App 用户不以租户作为站点可见性边界。
- Admin、账务、结算、运营数据必须按租户隔离。
- 用户界面不得把数据库 UUID 当作设备业务标识展示；设备使用 `ocpp_identity`，账务记录使用面向用户的参考号或本地化描述。
- 切换语言后，页面文案、状态、时间和后端结果提示必须匹配中文、英语、西语。

## 非目标

- 不开发充电桩隐藏开关。
- 不接入真实支付、真实地图或生产基础设施。
- 不迁移生产数据。
