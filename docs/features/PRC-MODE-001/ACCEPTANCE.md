# 验收标准

1. 新建但未定价的充电桩有效模式为 `unavailable`，不能正式投运、不能出现在 App、不能扫码启动。
2. 站点可设置 `paid`；价格必须大于 0，App 显示 COP/kWh。
3. 站点可设置 `free`；必须填写免费原因和未来截止时间，App 明确显示免费。
4. 站点可设置 `unavailable`；其下没有可用桩级覆盖价的设备停止接受新会话。
5. 充电桩可设置 `inherit`、`paid`、`free` 或 `unavailable`，覆盖优先于站点默认价。
6. 没有显式模式的旧正价 Tariff 兼容为 `paid`；旧零价 Tariff 不得兼容为 `free`。
7. 投运接口在有效模式为 `unavailable` 时返回 409 和稳定错误码。
8. App 列表与详情不返回草稿、测试、暂停或没有有效价格的充电桩。
9. 扫码检查与启动在无有效价格时返回 `TARIFF_NOT_CONFIGURED`，且不下发 RemoteStart。
10. 会话创建时生成且只生成一个价格快照；结算使用该快照。
11. 会话进行中修改 Tariff 不改变该会话最终使用的单价。
12. 结算不再回退到同租户其他站点或设备的任意 Tariff。
13. 免费会话生成 `0 COP` 账单与支付审计记录，但不生成金额为 0 的钱包变动流水，也不减少钱包余额。
14. Admin 显示模式、有效价格、来源和免费截止时间；不再使用 `¥`。
15. 定价变更写入租户隔离的 AuditLog，包含修改前后模式和原因，不记录敏感信息。
16. 后端定向测试、Admin 定向测试和 App 定向测试通过。
