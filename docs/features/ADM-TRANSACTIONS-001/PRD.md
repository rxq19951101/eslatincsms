# 目标

把后台“交易管理”从 OCPP 技术日志升级为租户运营人员可使用的充电记录台账，并让充电桩详情复用同一份历史数据。

# 用户与权限

- 仅具有 `transactions.read` 的当前租户后台用户可查询和导出。
- 数据必须由服务端依据当前租户上下文隔离，前端不得提交租户 ID 决定权限。

# 产品规则

1. 列表主标识为账单号；尚未生成账单时显示稳定的充电记录号，不以数据库 UUID 或 OCPP transaction ID 作为主标识。
2. 每条记录显示站点、充电桩展示编号/名称、枪口现场编号、用户参考、开始/结束时间、时长、电量、金额、币种、会话状态、支付状态。
3. 搜索、状态、站点、充电桩、日期范围均由服务端过滤；列表使用真实总数分页。
4. 金额优先采用 Invoice 权威总额；未结算会话可显示空值，不得把估算值冒充最终金额。
5. 异常标记至少覆盖：结束计量小于开始计量、已结束但缺少结束时间、平均功率明显超过枪口额定功率。
6. 导出必须应用与当前列表相同的过滤条件，内容按当前租户隔离。
7. 充电桩详情“历史记录”页签复用此 API，并固定按当前充电桩过滤。

# 非目标

- 本需求不改变计费、支付状态机或 OCPP 会话状态机。
- 本需求不生成缺失的发票或支付订单。
- 本需求不实现总管理员跨租户视角。
