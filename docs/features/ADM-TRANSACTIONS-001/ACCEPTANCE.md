# 验收标准

1. 当前租户只能看到自己的充电记录；跨租户引用返回 404 或空结果。
2. API 返回 `items/total/limit/offset`，翻页时记录无重复、无遗漏。
3. 搜索可匹配账单号、充电记录号、站点名称、充电桩展示编号/名称、OCPP 身份和用户参考。
4. 日期、站点、充电桩、会话状态和支付状态过滤在服务端生效。
5. 已开票记录显示 Invoice 的 `invoice_number/total_amount/status`；金额通过十进制字符串返回。
6. 缺少发票时金额为 `null`，页面明确显示未结算，不显示虚构金额。
7. 异常记录显示可国际化的异常代码，不依赖后端中文文案。
8. CSV 导出字段、过滤范围与当前列表一致，并包含 UTF-8 BOM 以支持常用表格软件。
9. 充电桩详情历史页签可显示该桩最近记录并进入完整充电记录页。
10. 中文、英文、西班牙语均无硬编码混合文案。
