# 验收标准

1. Web 点击“删除账号”后显示标题、后果说明、取消和确认操作。
2. 点击取消只关闭对话框，不调用删除账号 action。
3. 点击确认只提交一次；提交期间取消和确认操作不可重复触发。
4. 删除失败时保留当前页面并显示国际化错误信息。
5. 删除成功后进入 `Welcome` 页面。
6. 对话框支持键盘和辅助功能语义，不调用 `window.confirm`。
7. 原生端仍保留二次确认、取消、确认、成功跳转和失败反馈行为。
8. 直接相关组件测试和 App TypeScript 检查通过。
