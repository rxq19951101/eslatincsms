# Web 删除账号确认修复

## 问题

个人设置页使用 React Native `Alert.alert` 进行删除账号确认。该交互在 Web 端没有可靠实现，用户点击“删除账号”后没有任何可见反馈。

## 目标

- 点击“删除账号”后，在 Web 和原生端都显示明确的二次确认。
- 取消操作不得调用删除接口。
- 确认操作只调用一次删除接口，提交期间禁止重复点击。
- 删除失败时在当前页面显示可见错误信息。
- 删除成功后继续进入欢迎页。

## 实现范围

- 提供基于 React Native `Modal` 的可复用确认对话框，不依赖浏览器原生 `window.confirm`。
- 个人设置页使用该对话框承载删除确认。
- 复用现有中文、英文和西班牙文文案，不修改删除账号业务契约。

## 非范围

- 不修改删除账号后端 API、Redux action 或导航参数。
- 不调整账户页其他产品结构。
- 不处理首页 Logo 清晰度问题。
