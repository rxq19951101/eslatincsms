# 验收标准

1. 空名称、空地址、纯空格地址、越界坐标和 `(0, 0)` 均无法创建或保存站点，API 返回 422。
2. 合法站点可以创建；数据库内部 ID 不包含名称且页面不展示。
3. 充电桩身份仅接受 1-64 位 ASCII 字母、数字、点、下划线、冒号或连字符；重复身份返回 409。
4. 所有新增/编辑 API 对长度、枚举和数值范围执行后端校验，前端显示三语言字段错误。
5. 远程启停、重置接口未认证返回 401，无权限或跨租户返回 403；前后端字段一致。
6. 远程停止使用活动会话的 OCPP transaction ID，不使用 EVSE ID。
7. 钱包调账金额非零、两位小数内、原因必填；重复幂等键不重复入账。
8. 租户开通任一步骤失败时不留下租户、管理员或成员关系残件。
9. 内部实体使用 UUID 主键；外部可读编号或设备身份使用独立唯一列。
10. Admin 侧栏、登录页和 favicon 使用矢量/透明品牌资产，在深浅色背景与高 DPI 下清晰。
11. 后端、Admin 单元测试、集成测试和浏览器交互回归通过。
