# 目标

为 Admin 所有写操作建立前后端一致、后端权威的校验规则；修复远程控制权限和契约；统一内部 ID；从 EsLatin AI 源文件建立适配深浅色界面的矢量品牌资产。

# 产品规则

- 站点名称、地址和有效坐标为创建站点的必填条件，`(0, 0)` 不得作为有效位置。
- 内部数据库 ID 由服务端生成，前端不可编辑，页面默认不展示。
- 充电桩 OCPP 身份是外部业务标识，不等同于内部数据库 ID，并保持全平台唯一。
- 钱包调账必须填写原因并记录审计；金额使用 Decimal 且最多两位小数。
- 租户开通（租户、首个管理员、成员关系）必须原子化。
- 系统配置只允许已注册的配置键和类型。
- 远程控制必须认证、校验租户归属和权限，并记录幂等命令与审计日志。
- Admin 使用中文、英语、西班牙语三语言；错误信息也必须国际化。

# 非目标

- 不部署生产环境。
- 不迁移历史测试数据；开发数据库允许重建基线。
- 不改变已冻结的 OCPP 协议版本。
