# ADR-001：内部 UUID 与外部业务标识分离

状态：Accepted

## 决策

- 内部实体统一使用 PostgreSQL UUID 主键，由服务端生成。
- OCPP identity、序列号、订单参考号等作为独立业务列并单独唯一约束。
- API 路由可在本阶段继续接受现有业务标识，以降低前端/OCPP 改造范围；数据关系使用 UUID。

## 原因

- 外部输入不应控制内部关系主键。
- UUID 提供统一、不可变且足够大的标识空间。
- 业务标识可独立修改格式、作用域和展示规则。

## 代价

- 需要更新外键、查询和序列化。
- 开发数据库需重建，不兼容旧测试数据。
