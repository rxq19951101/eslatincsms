# App 账户信息架构与账号管理入口

## 目标

将账户页从单一长列表调整为清晰的个人设置入口，解决页面无法完整滚动、删除账号入口暴露在根页面以及功能分组不清的问题。

## 产品结构

### 账户根页面

- 顶部保留用户头像、姓名和邮箱，整个资料卡可进入“个人设置”。
- 按用途拆分为以下区域：
  - 充电与支付：充电历史、支付与钱包（功能开启时）。
  - 偏好设置：语言。
  - 支持与法律：帮助中心、隐私政策、服务条款、关于。
- 退出登录保留为根页面底部的独立操作。
- 根页面不得直接显示“删除账号”。
- 整个页面必须可以垂直滚动，在较小屏幕上也能访问全部入口。

### 个人设置二级页面

- 保留邮箱、姓名、手机号信息。
- 页面标题和账户页入口统一为“个人设置”语义。
- 页面可垂直滚动。
- 页面底部增加独立的“账号管理”危险区域，提供删除账号入口和后果说明。
- 删除账号继续使用现有二次确认和现有删除逻辑；不得一触即删。

## 国际化

- 新增的区域标题、说明和入口必须提供中文、英文、西班牙文。
- 不允许在组件中硬编码面向用户的文案。

## 非范围

- 不修改账号删除后端 API。
- 不改变登录、退出登录和个人资料保存契约。
- 不新增支付能力、预订能力或通知设置。
- 不修改底部 Tab 导航。
