# 验收标准

1. 账户根页面可上下滚动，较小屏幕可访问全部功能。
2. 根页面按充电与支付、偏好设置、支持与法律进行分组。
3. 用户资料卡或“个人设置”入口可进入现有 `PersonalInfo` 路由。
4. 根页面不显示删除账号按钮。
5. 个人设置二级页面可滚动，并在独立账号管理区域显示删除账号入口和后果说明。
6. 删除账号仍需二次确认，成功、失败和加载状态保持有效。
7. 中文、英文、西班牙文新增文案完整且类型一致。
8. App TypeScript 检查和直接相关测试通过。
