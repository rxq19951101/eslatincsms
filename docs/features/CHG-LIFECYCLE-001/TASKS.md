# 任务

## 产品与契约

- [x] 冻结站点归档、充电桩退役和永久删除产品规则。
- [x] 冻结生命周期、预检、归档查询和错误响应 API 契约。

## 独立实现任务

- [x] 测试阶段兼容层：使用现有 `is_active`、`commissioning_status` 和 `AuditLog` 映射归档/退役生命周期，不新增数据库迁移。
- [x] 后端查询：活动站点、Dashboard、App 和绑定候选排除归档站点及退役充电桩；Admin 站点详情排除退役设备。
- [x] 后端充电桩生命周期：实现退役预检、同步退役、恢复和严格永久删除；存在进行中会话或未完成账务时拒绝退役。
- [x] 后端业务门禁：扫码、创建订单、远程启动、OCPP 认证和二维码校验拒绝退役设备及归档站点。
- [x] 后端站点生命周期：实现归档预检、归档、恢复和严格永久删除。
- [x] 后端迁移安全：限制同租户活动站点，并拒绝迁移存在进行中或历史会话、订单的充电桩。
- [x] 后端审计：记录退役、恢复、归档、迁移和永久删除操作。
- [x] 后端资产归档查询：实现归档站点和退役充电桩的租户隔离列表、筛选及操作人信息。
- [x] Admin 充电桩详情：增加退役阻塞反馈、恢复和严格永久删除交互。
- [x] Admin 站点详情：增加归档预检、阻塞项处理入口、恢复和严格永久删除交互。
- [x] Admin 资产归档：增加归档站点和退役充电桩列表、筛选与历史入口。
- [x] Admin 普通列表与统计：排除退役充电桩及归档站点，并统一正常计数。
- [x] QA 后端：覆盖状态迁移、幂等、租户隔离、权限、进行中会话、历史归属和永久删除阻塞。
- [x] QA Admin：覆盖退役桩不在站点显示、归档预检、确认流程、恢复和错误提示。
- [ ] 集成验证：完成站点归档、设备退役阻塞、恢复、永久删除阻塞及历史设备迁移阻塞的定向回归。

## 生产阶段延期任务

- [ ] 增加站点 `active / closing / archived` 专用生命周期字段。
- [ ] 增加充电桩 `active / retiring / retired` 专用生命周期字段及退役元数据。
- [ ] 为会话与订单增加不可变站点快照并安全回填历史数据。
- [ ] 实现进行中会话结束后的异步自动退役。

## 执行顺序

1. 测试阶段生命周期兼容层。
2. 后端查询过滤。
3. 充电桩生命周期与业务门禁。
4. 站点生命周期与迁移安全。
5. 审计与后端测试。
6. Admin 详情交互。
7. Admin 资产归档。
8. QA 与集成验收。

每项均为独立验收任务；完成后先由项目负责人确认，再进入下一项。
