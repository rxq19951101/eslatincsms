# 验收标准

1. 五个主 Tab 顶部标题使用同一组件，边距、字号和垂直节奏一致。
2. 首页不再展示占用大块纵向空间的完整 Logo；仅显示紧凑图形标识、标题、副标题和右侧刷新入口。
3. 收藏、扫码、钱包、账户不重复展示 Logo，标题位于统一位置。
4. 首页列表/地图切换、搜索和刷新行为不变。
5. 收藏、扫码、钱包、账户原有功能不变。
6. 中文、英文、西班牙文标题和副标题继续来自现有 i18n 文案。
7. 根页面顶部组件具备可定位的 testID，并有最小组件测试或页面测试覆盖。
8. App TypeScript 检查和直接相关测试通过。
