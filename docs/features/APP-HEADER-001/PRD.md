# App 根页面顶部结构统一

## 目标

统一首页、收藏、扫码、钱包和账户五个主 Tab 的顶部结构，解决 Logo 体量过大、标题位置不一致和页面视觉重心混乱的问题。

## 产品规则

- 五个主 Tab 使用同一套根页面顶部组件、水平边距、标题字号和安全区规则。
- 首页在标题左侧使用官方 Logo 的紧凑图形标识；不得再次堆叠大幅完整 Logo。
- 收藏、扫码、钱包、账户只显示页面标题，不重复展示品牌 Logo。
- 首页刷新操作保留在顶部右侧；其他页面原有业务操作不新增、不删除。
- 页面副标题只在确有解释价值时显示，并与标题归入同一顶部信息区。
- 登录、注册等品牌展示页继续使用完整 Logo。
- 二级页面继续使用居中标题和返回按钮的 `ScreenHeader`，不改成根页面样式。

## 范围

- `HomeScreen`
- `SavedScreen`
- `ScanScreen`
- `MyWalletScreen`
- `AccountScreen`
- 新增可复用的根页面顶部组件

## 非范围

- 不改变底部 Tab 导航。
- 不改变站点、扫码、钱包、账户的业务逻辑或 API。
- 不在本需求中调整账户信息架构、退出登录或删除账号入口。
- 不调整二级页面导航结构。
