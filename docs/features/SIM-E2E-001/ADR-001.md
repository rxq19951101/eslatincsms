# ADR-001：场景编排与协议模拟分层

状态：Accepted

## 决策

- 设备协议 actor 与 Admin/App/Payment actor 分离。
- YAML 只描述业务意图，runner 负责调度，actor 负责协议，assertion 负责观察。
- OCPP 仅冻结 1.6J 标准 frame；每条消息保留可控 UniqueId。
- E2E 通过公共 API 和 UI 验证；不增加生产可用的任意数据库测试接口。
- 支付使用本地 fake provider，不连接真实支付网络。

## 理由

设备、用户、管理员和支付是不同信任边界。分层后才能复用场景、隔离 secret、准确判断协议成功与业务完成，并让失败证据可追踪。
