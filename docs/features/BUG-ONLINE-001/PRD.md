# 站点在线充电桩计数一致性修复

## 问题

Admin 站点列表可能把最近五分钟内更新过、但当前状态已经是 `Offline` 的充电桩计为在线，导致列表显示的在线数量与站点详情不一致。

## 产品规则

- 充电桩只有在最近五分钟内存在有效状态更新，并且有效状态不是 `Offline` 时才计为在线。
- 站点列表、站点详情和 Dashboard 使用相同的五分钟在线窗口和 `Offline` 排除规则。
- 过期心跳、缺少心跳、当前状态为 `Offline` 的充电桩均计为离线。
- 本修复不修改资产生命周期、历史业务数据或数据库结构。

## 范围

- 修正 Admin 站点列表的 `online_charge_points_count`。
- 增加新鲜 `Offline` 状态不计在线的回归测试。
- 修复验证后一次性重新构建本地 CSMS 和 Admin 容器。
