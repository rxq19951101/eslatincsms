# 验收标准

1. 欢迎页使用 `EsLatin 定稿2.ai` 白底版本导出的清晰资产，不出现黑色方块。
2. Logo 中已有 ESLATIN 字标时，页面不再重复显示品牌名。
3. 原生启动背景、应用图标、欢迎页、登录页与蓝/青品牌色一致。
4. 中文、英语、西语文案仍随语言切换。
5. 登录、注册入口和返回交互保持可用且具备可访问标签。
6. TypeScript、相关组件测试和 Expo Web 构建通过。
7. `app/src` 和 `app/App.tsx` 不再包含 Emoji 字符；勾选、地图、充电、费用、位置和空状态均使用矢量图标或纯文本。
8. Logo 使用 `EsLatin 定稿2.ai` 导出的透明背景资产，页面中没有可见白色图块、Logo 卡片、边框或悬浮阴影。
9. 登录页问候语不含 Emoji，标题、说明和表单形成统一且克制的视觉层级。
10. 首页标题左侧展示包含图形与字标的完整 EsLatin Logo，不再只显示字母。
11. 未登录用户可以从邮箱登录页进入语言设置，并立即切换中文、英语和西语。
12. 账户页语言设置以独立二级页面呈现，不再使用横向 Tab；选中状态清晰且返回后语言保持生效。
