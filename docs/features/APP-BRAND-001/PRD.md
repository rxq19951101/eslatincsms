# App 品牌入口改造

## 背景

当前 App 欢迎页使用黑底 Logo 位图，和浅色界面割裂，同时重复显示品牌名称。用户已提供 `EsLatin 定稿2.ai` 白底矢量源稿，要求将其用于 App。

## 范围

- 从 `EsLatin 定稿2.ai` 导出 App 品牌资产，不重新绘制 Logo。
- 更新原生启动图、应用图标、欢迎页和邮箱登录页。
- 将 App 的全局品牌色调整为与 Logo 的电光蓝/青色体系一致。
- 从白底 AI 源稿导出透明背景品牌资产，使 Logo 直接融入页面背景，不使用白色方块、独立 Logo 卡片或夸张阴影。
- 删除 App 源码中的可见 Emoji；功能性图形使用现有矢量 Icon 组件，调试日志使用纯文本级别前缀。
- 登录页采用克制、专业的品牌层级，不在问候语中使用 Emoji。
- 首页标题使用 AI 源稿导出的完整紧凑 Logo，不以纯文字 `ESLATIN` 代替品牌标识。
- 邮箱登录页提供清晰但克制的语言入口，未登录用户也能切换中文、英语和西语。
- 账户页不再内嵌临时按钮组；登录页和账户页共用独立的二级语言设置页。
- 保持现有三语言、认证逻辑、导航和 API 契约不变。

## 非范围

- 不修改注册、登录、充电、支付等业务规则。
- 不重构全部业务页面布局。
- 不生成或替换用户提供的 Logo 图形。
