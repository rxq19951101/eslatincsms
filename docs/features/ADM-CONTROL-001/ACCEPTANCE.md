# 验收标准

1. 远程启动请求必须包含明确的 connector_id 和 3-200 字符操作原因。
2. 后端生成 `OPS-` 开头且不超过 20 字符的运维 idTag；客户端提供的 id_tag 不得被发送给设备。
3. 设备离线、枪口非 Available、状态未知或已有 ongoing 会话时，后端拒绝启动且不发送命令。
4. 远程控制页面显示所有枪口的现场编号与当前状态，不默认第一枪。
5. 多个活动会话时，停止操作绑定用户明确选择的会话。
6. Soft Reset 是默认入口；Hard Reset 必须位于危险操作并二次确认。
7. 解锁必须选择枪口；空的配置管理按钮不得保留。
8. 操作原因、枪口/会话、运维 idTag、管理员和命令结果可通过审计记录追踪。
9. 无 `chargers.control` 时不能调用控制接口，且页面不显示控制操作。
10. 新增交互支持中文、英语和西班牙语。
