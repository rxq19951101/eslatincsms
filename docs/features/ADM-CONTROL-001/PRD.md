# 普通租户充电桩远程控制安全

后台远程控制定位为运营调试与故障处置能力，不用于冒充 App 用户发起普通充电。所有命令必须操作明确的设备、枪口或会话，并留下操作原因和审计记录。

## 产品规则

- 远程启动：管理员明确选择枪口并填写原因；服务端生成最多 20 字符的运维 idTag，客户端不能决定用户身份。
- 启动前置校验：设备 WebSocket 在线、枪口状态为 Available、枪口无 ongoing 会话；不满足时不发送 OCPP 命令。
- 远程停止：管理员从活动会话列表明确选择会话并填写原因，不允许默认选择第一笔会话。
- 重置：默认 Soft；Hard 放入高级危险操作，显示影响说明并二次确认。
- 解锁：必须明确选择枪口并填写原因。
- 配置管理：按钮必须进入真实配置管理交互；未实现前不得显示可点击的空按钮。
- 所有命令沿用租户隔离、`chargers.control`、幂等 Outbox 和 AuditLog。

## 非范围

- 改变或猜测当前冻结的 OCPP 协议版本。
- 为运营远程启动创建 App 用户订单或扣款。
- 修改充电会话状态机、支付或结算规则。
- 本阶段不处理交易列表和统计报表。
