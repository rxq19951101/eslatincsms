# 验收标准

1. 选择中文后，所有 App 页面和交互中的系统文案均显示中文；英语和西语同理。
2. 注册、登录、邮箱验证、密码重置、首页、充电、钱包、支付、账户及导航不存在用户可见硬编码中文或英语。
3. 中、英、西三套词典键结构完全一致，缺失键由自动化测试拦截。
4. 硬编码扫描测试覆盖 JSX 文本、常见组件属性、Alert、占位符和无障碍标签，并允许明确记录的非 UI 例外。
5. 验证码输入只接受数字且最多 6 位；少于或多于 6 位不能提交。
6. 验证码页面可以点击空白处收起键盘，并提供键盘完成动作；验证按钮不会被永久遮挡。
7. iOS 一次性验证码自动填充仍可用。
8. 相关单元测试、TypeScript 检查和 App 针对性测试通过。
