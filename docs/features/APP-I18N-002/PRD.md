# App 全量国际化与验证码交互治理

## 背景

App 已提供中文、英语和西语切换，但部分页面仍直接写死中文或英语，造成同一页面中英混合。邮箱验证码页面同时存在长度约束与键盘交互问题。

## 范围

- 扫描 `app/src` 和 `app/App.tsx` 的全部用户可见文案，包括页面、导航、弹窗、按钮、表单、占位符、状态、错误、空状态和无障碍标签。
- 所有用户可见文案统一通过现有 `useI18n().t` 或非 React 场景的动态翻译入口读取。
- 为中文、英语、西语补齐语义一致的翻译键，并保证三套词典结构一致。
- API 返回的技术错误保留兜底处理，但不得直接把固定中文或英语作为 UI 默认文案。
- 邮箱验证码仅允许输入 6 位数字；前端输入、提交校验和按钮状态使用同一规则。
- 验证码页面支持点击空白区域、键盘完成键或提交动作收起键盘，同时保持验证码自动填充能力。
- 修复注册页及认证流程中全部混合语言文案。

## 非范围

- 不修改后端 API、数据库、认证规则或验证码有效期。
- 不重新设计 App 视觉系统。
- 不翻译开发日志、源码注释、测试描述、协议字段、品牌名和用户/站点真实数据。
