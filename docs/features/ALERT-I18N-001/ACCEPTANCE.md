# 验收标准

1. 中文、英文、西班牙语下，告警主标题、主描述、严重程度和状态均完整本地化。
2. 主列表不显示告警、充电桩或 EVSE 的数据库 UUID。
3. 设备告警显示站点名称、OCPP Identity 和 EVSE 编号；字段缺失时显示本地化“未关联”。
4. 英文 OCPP 原始信息只在可展开技术详情中显示。
5. “查看站点”和“查看设备”跳转到对应管理页面。
6. 待处理告警保留确认和解决操作；已解决告警不能重复处理。
7. 后端保持 tenant_id 隔离，不能通过告警关系读取其他租户资产。
8. API、前端组件、三语言和空值场景均有自动化测试。
