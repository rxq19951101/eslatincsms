# 告警可读性与国际化

运营人员必须能在告警列表中立即识别告警类型、严重程度、所属站点、充电桩和 EVSE，并能在中文、英文和西班牙语之间切换而不出现业务文案混杂。

本阶段仅包含结构化告警展示契约、三语言文案、紧凑列表和设备/站点跳转。不包含高级筛选、历史时间线、批量处理或告警规则编辑。

## 产品规则

- 数据库 UUID 只用于内部关联，不作为主要设备标识展示。
- 系统告警以稳定 `alert_code` 和 `message_params` 表达；前端负责本地化。
- OCPP/厂商原始文本只显示在技术详情中，不进入主标题或主描述。
- 设备告警必须返回租户隔离后的站点、充电桩和 EVSE 上下文。
- 缺少站点、设备或 EVSE 时必须明确显示“未关联”，页面不得崩溃。
