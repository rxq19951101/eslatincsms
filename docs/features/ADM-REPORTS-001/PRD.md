# 目标

让普通租户管理员按日期和站点查看、导出收入、电量和订单趋势，统一报表口径、币种与错误反馈。

# 产品规则

1. 默认查询最近 30 天，支持最近 7/30/90 天快捷选择和自定义起止日期。
2. 支持按当前租户的单个站点筛选；不选择站点表示当前租户全部站点。
3. 收入只统计已支付 Invoice 的权威金额，币种固定显示为当前结算币种 `COP`。
4. 电量仅统计有效的非负计量差；金额和电量不得通过二进制浮点数累计。
5. 订单统计使用业务 Order，不以 OCPP transaction ID 代替订单。
6. 页面分别展示收入、电量、订单图表；导出时必须明确选择报表类型，并应用与页面相同的日期和站点条件。
7. 加载失败必须显示错误和重试入口，不得无限显示加载状态或将错误冒充空数据。
8. 本需求只覆盖普通租户作用域，不扩展总管理员跨租户报表产品能力。
