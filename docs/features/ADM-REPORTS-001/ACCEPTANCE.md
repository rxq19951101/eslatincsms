# 验收标准

1. 普通管理员只能查询和导出当前租户数据。
2. 日期起点晚于终点返回 422；自定义日期两端必须同时提供。
3. 站点不属于当前租户时返回 404，且不泄露其他租户信息。
4. 收入与 Invoice 已支付总额一致，金额以十进制字符串返回并显示 `COP`，页面不出现 `¥`。
5. 电量忽略结束计量小于开始计量的异常记录。
6. 订单数量与业务 Order 表相同过滤范围一致。
7. 三张图表共享同一日期和站点条件；切换条件后更新全部图表。
8. CSV 导出类型可选 revenue、energy、orders，字段与同类型 API 一致并带 UTF-8 BOM。
9. 请求失败时三语言显示错误信息和重试按钮。
10. 空数据、加载中、错误状态相互独立。
11. 起止日期控件在中文、英文、西班牙语下分别显示对应语言的占位、月份和操作文案；切换语言后立即更新，并仍提交 `YYYY-MM-DD` 值。
