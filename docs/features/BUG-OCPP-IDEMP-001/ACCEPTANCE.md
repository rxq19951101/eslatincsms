# 验收标准

1. 首次远程启动成功后，即使连接器状态已变为 `Charging` 且已有进行中会话，相同请求使用同一幂等键仍返回首次结果，响应包含 `idempotent_replay: true`。
2. 上述重放不得再次调用设备命令发送器，且只保留一条对应 Outbox 命令记录。
3. 同一租户内，同一幂等键改用于另一充电桩时返回 409，错误码为 `IDEMPOTENCY_KEY_REUSED`。
4. 同一幂等键用于同一充电桩但修改连接器、操作原因或运维身份派生字段时返回 409，错误码为 `IDEMPOTENCY_KEY_REUSED`。
5. 权限与租户范围校验仍在幂等结果读取之前执行；跨租户请求不能读取原命令结果。
6. 不新增数据库迁移，现有远程启动成功、设备拒绝和传输失败重放测试继续通过。
