title: 远程启动幂等重放顺序修复
status: ready-for-dev
---

# 问题

远程启动首次成功后，充电桩和连接器状态会进入充电中。相同租户、相同充电桩、相同请求使用同一幂等键重放时，接口当前先检查连接器实时状态和进行中会话，导致返回 409，而不是首次请求的已记录结果。

# 产品规则

- 已通过当前权限与租户范围校验的请求，应先识别同一幂等命令，再执行会变化的设备状态前置检查。
- 同一租户、同一充电桩、同一动作、相同请求参数与同一幂等键，必须返回首次命令的已记录结果，不再次下发 OCPP 指令。
- 同一租户内，同一幂等键被用于不同充电桩、不同动作或不同业务参数时，必须返回 409，禁止错误重放。
- 不提供幂等键时，保持现有行为，每次创建独立命令。
- 当前权限校验、多租户隔离和充电桩可见范围不变。

# 范围

本需求仅修复后台远程启动接口的幂等重放与幂等键复用校验，不修改数据库结构，不扩展到远程停止、重置和解锁接口。
