# Public charger and connector labels

Add stable, short, site-scoped public labels so drivers can match the App with
the physical charger. Database UUIDs and OCPP identities remain technical
identifiers and must not be rendered to drivers.

Scope: public charger code, optional public name/location hint, connector
physical reference, Admin provisioning, App site detail display, zh/en/es.
Out of scope: automatic connector discovery, OCPP protocol changes, billing,
QR token format changes, production deployment.
