# Acceptance

- A charge point has a site-scoped `display_code` such as `A01`.
- Duplicate codes in one site are rejected; the same code in another site is allowed.
- App site detail shows each charger and connector using public labels.
- App does not render UUIDs or OCPP identities as charger names.
- Connector status, standard and maximum power remain visible per connector.
- Admin creates and displays public labels with clear validation.
- New labels are translated in Chinese, English and Spanish.
- Existing OCPP authentication, QR lookup and charging APIs continue to work.
