# 验收标准

1. `GET /api/v1/app/sites` 对每个启用站点最多返回一条记录。
2. 同一站点下多个充电桩的 `charger_count`、`total_connectors`、`available_connectors` 正确聚合。
3. 站点总体状态不使用超过 5 分钟的接口状态冒充在线状态。
4. `GET /api/v1/app/sites/{site_id}` 返回站点、充电桩和接口三层数据。
5. 列表支持经纬度、半径和数量限制，并按距离排序。
6. App 用户可以跨租户读取公开站点，传入 `X-Tenant-Id` 不得缩小公开目录。
7. 未认证请求返回 401；不存在或停用站点返回 404。
8. 现有 `/api/v1/app/chargers` 行为保持不变。
9. 定向 API 测试通过。
10. App 首页使用站点列表契约，同一站点不会因包含多个充电桩而重复显示。
11. App 站点详情按站点、充电桩、接口三层呈现，导航参数使用 `siteId`。
12. 列表和详情返回站点及每种充电选项的状态分项数量；总数必须等于所有分项之和。
13. 当同一充电选项包含一个充电中接口和一个离线接口时，App 明确显示“1 充电中 · 1 离线”，不能只显示“0/2 可用”。
14. App 的主状态优先表达是否可立即充电；无可用接口但存在充电中接口时显示“暂无空闲”，并保留状态分项说明。
