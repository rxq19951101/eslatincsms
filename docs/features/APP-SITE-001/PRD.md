# App 公开站点聚合 API

## 背景

当前 App 发现接口按 `ChargePoint` 返回记录，但用户界面把每条记录显示成一个站点，导致同一地点出现多个重复站点，并混淆站点、充电桩和充电接口三个层级。

## 目标

- App 发现入口按 `Site` 返回唯一站点。
- 聚合同一站点下所有启用充电桩和接口的实时可用数量。
- 分别返回可用、充电中、离线、故障、占用和不可用数量，避免用 `0/N 可用` 隐藏真实设备状态。
- 提供站点详情层级：站点 → 充电桩 → 接口。
- App 用户仍可跨租户读取所有公开、启用且具备坐标的站点；租户结算规则不变。

## 非范围

- 本阶段不实现收藏。
- 本阶段不调整 App 首页视觉布局。
- 不删除或改变现有 `/api/v1/app/chargers` 契约。
- 不修改充电启动、支付或租户结算规则。
- 不修改 OCPP 原始状态，仅在公开站点接口中归一化为用户可理解的状态分组。
