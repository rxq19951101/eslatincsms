# 验收标准

1. 普通租户只能看到本租户的 ongoing 会话。
2. 每条记录至少显示站点名称、充电桩 display_code、枪口 physical_reference、开始时间、当前电量、当前功率、时长、最后计量时间和状态。
3. 有可用费率与电量时显示 COP 预估费用；数据不足时显示“暂不可用”，不得显示错误的 0 元。
4. OCPP Identity 和 OCPP transaction ID 不作为列表主识别信息。
5. 点击停止时必须出现包含站点、充电桩和枪口的二次确认。
6. 用户取消确认时不发送请求。
7. 确认后只使用所选行的业务 `session_id` 调用远程停止接口，并携带幂等键；客户端不得读取或提交 OCPP 标识。
8. 停止成功、设备拒绝、设备离线和接口错误均有明确反馈；请求完成后刷新列表。
9. 无 `chargers.control` 权限时不显示停止操作。
10. 中文、英语和西班牙语不存在新增硬编码混用。
11. 公共运营响应不保留 OCPP Identity、OCPP transaction ID、EVSE ID 或重复的连接器编号字段。
12. 后端测试覆盖跨租户隔离、站点/设备/枪口映射和预估费用缺失场景；前端测试覆盖确认、取消和错误反馈。
