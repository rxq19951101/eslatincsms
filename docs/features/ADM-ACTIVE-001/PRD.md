# 普通租户进行中充电运营台

普通租户运营人员必须能够在一个页面定位正在充电的站点、充电桩和枪口，查看实时计量与预估费用，并对明确选中的会话执行远程停止。

## 范围

- 进行中会话列表展示站点、充电桩运营编号、枪口现场编号、用户引用、开始时间、时长、当前电量、功率、预估费用和最后计量时间。
- OCPP Identity 和 OCPP transaction ID 降为技术辅助信息。
- 每行提供查看充电桩和远程停止入口。
- 停止操作必须二次确认，确认内容包含站点、充电桩、枪口和交易号。
- 停止请求沿用已有幂等和审计能力，发送后刷新会话状态并明确展示成功或失败。

## 非范围

- 新建数据库表或修改会话状态机。
- 改变计费结算结果；进行中费用仅标记为预估。
- 新增远程停止协议或改变当前冻结的 OCPP 协议版本。
- 全量重构交易管理与统计报表。

## 权限与租户边界

- 列表数据仅来自当前授权租户。
- 查看需要现有交易/会话读取权限。
- 远程停止需要 `chargers.control`。
- 后端继续从认证上下文确定 tenant_id，不接受客户端 tenant_id 作为授权依据。
