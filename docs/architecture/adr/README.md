# Architecture Decision Records

ADR 记录重大技术决策的原因，不替代当前完整架构。状态使用 `proposed`、`accepted`、`superseded` 或 `rejected`。

命名：`ADR-XXX-short-title.md`。逆转 accepted ADR 前必须新建 ADR，并在旧 ADR 标记 superseded。

当前索引：

- ADR-001：仓库文档是项目持久记忆。
- ADR-002：模块化单体与 PostgreSQL/Redis 事实边界。
- ADR-003：OCPP 高频遥测采用实时快照与采样持久化。
- ADR-004：Mercado Pago 托管支付和敏感数据边界。
